          6 字幕断行排版 （只增删换行、或把断点处一个空白替换为换行；不改字符顺序、时间轴、锚点、锁定与 .stc 指纹）

          排版规则说明
          • 用 Unicode 字素簇切分（regex 的 \X；emoji 组合、注音 / 声调组合不拆开）， 以 wcwidth.wcswidth 计列宽（汉字 / 全角字符 2 列，ASCII 1 列，控制字符 0 列）。
          • 候选断点限于空白处（该空白替换为换行、不再保留）、标点之后、相邻汉字之间； 正文里既有的换行可保留或删除。
          • 断点罚分：句末标点 。！？； = 0，空白 = 1，其他标点 = 2，相邻汉字之间 = 3。
          • 禁止 ，。！？；：、）》】」』 出现在行首；禁止 （《【「『 留在行尾。
          • 动态规划只接受所有行都不超宽的方案，依次最小化： ① 总罚分 → ② 各行剩余列数平方和 → ③ 断点位置字典序（更靠前的断点优先）。
          • 无解的条目会逐条列明原因（如最少需要的行数超过上限、存在切不开的超宽连续片段、 首尾标点固有违规、单个字素簇超宽）。
          • 可单条接受、也可全部接受；「撤销本轮」一次恢复本轮生成建议以来的接受状态。 排版版 SRT 只写入已接受的换行（时间仍走当前锚点 / 锁定映射，同样做冲突拦截）； 第 1 步工具栏的普通「⬇ 导出 SRT」始终保持原样、不含排版换行。 排版状态不写入 .stc 工程。
          设置每行列数与最多行数后，点击「生成排版建议」，在此逐条对照原文与建议。

          或粘贴译文 SRT 文本

          译文时间倒挂或任意两条正长度重叠（端点相接允许）时拒绝导入； 多对一 / 一对多经相交传递合并为同一组，每条字幕只出现一次。 每组导出一条：源文、译文各自按原顺序换行拼接后上下排列；时间取该组源字幕当前校准预览的最早开始与最晚结束，译文时间只参与配对。 存在未配对条目（任一侧）或实时预览有冲突时禁止双语导出；重新导入源 SRT 会清空配对。 配对仅用于双语导出，普通导出 / 排版版导出 / .stc 工程均不受影响。

          导入源 SRT 后，在此选择（或粘贴）对应的译文 SRT，自动按时间区间配对分组。
